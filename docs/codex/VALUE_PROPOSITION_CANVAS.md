# veiga-translator 가치제안 캔버스 — 고객 원안과 정량 근거

작성·확인일: 2026-11-10  
작성 주체: Codex. 이후 Codex의 VPC 문서·PPT는 이 폴더에서 별도로 작성한다. AGY 원본 경로는 열람용으로 보존한다.  
기준 원안: [사용자가 작성한 VPC](../myresearch/vpc.md)  
PPT 구성·스타일 기준: [AGY 원본 PPT](../planning/final/VALUE_PROPOSITION_CANVAS.pptx)

이 문서는 PPT 제작에 사용할 VPC 문안, 정량 근거, 도표 위치, 발표 노트를 함께 정리한 내용 기준본이다. 사용자 원안의 **일본어 콘텐츠 이해 → 대화 맥락 파악 → 원하는 말 표현 → 참여와 소속감**을 유지한다. 일본 드라마·예능·인터뷰·라이브·서브컬처 콘텐츠 시청자를 고객 후보에 포함한다.

수치는 원자료에 직접 제시된 값만 사용한다. 인구 환산, 임의의 수요 비율, 예상 점유율·구매 전환율·시장 금액은 넣지 않는다. 외부 연구 결과는 해당 연구의 결과로, 앱의 기능은 구현 사실로, 고객에게 줄 효과는 검증할 가치 가설로 구분한다.

## 1. 고객 정의와 가치제안

### 고객 정의

**일본어 콘텐츠를 즐기고 싶지만, 일본어 이해·표현 능력의 제약으로 내용을 충분히 이해하거나 대화에 참여하기 어려운 한국어 사용자.**

| 고객 후보 | 고객이 하려는 일 | 연결되는 기능 | 정량 자료가 확인하는 범위 |
|---|---|---|---|
| 일본 드라마·예능·인터뷰 등의 시청자 | 대사와 이야기 흐름을 이해하며 시청하기 | 한국어 자막, 대화 로그, 주제 요약 | 일본 실사 드라마의 글로벌 시청 지표는 확인됨[3][R3]. 국내 해당 시청자의 번역 필요 비율·인원은 미확인 |
| 일본어 라이브 방송 시청자 | 진행 중인 이야기를 이해하고 반응·채팅으로 참여하기 | 자막, 주제 요약, 일본어 답장 번역 | 해외 시청 실험에서 번역·부가 정보·댓글 경험을 평가함[4][R4]. 국내 일본어 라이브 시청자 수는 미확인 |
| 일본 창작자·배우·아티스트·게임·서브컬처 콘텐츠의 팬 | 좋아하는 대상의 말을 이해하고 자신의 생각을 표현하기 | 청취와 답장 번역, 최근 대화 맥락 참조 | 국내 일본 대중문화·콘텐츠 소비 조사[1][R1][2][R2]는 고객 후보의 존재를 설명함. 팬 전체를 앱 고객으로 간주하지 않음 |

집단은 중복될 수 있어 합산하지 않는다. 현재 자료로 어느 집단이 가장 많이 쓰거나 결제할지 순위를 매기지 않는다.

### 가치제안 문안

> 일본어 콘텐츠의 말을 한국어로 이해하고, 대화의 흐름을 파악하며, 전하고 싶은 말은 일본어로 표현할 수 있도록 돕는 시청·소통 번역 도구.

### 적용 범위

현재 구현은 YouTube 중심의 브라우저 확장과 로컬 백엔드다. 드라마를 포함한 여러 장르를 고객 범위에 포함하되, Netflix 등 개별 스트리밍 서비스에서의 실행·오디오 캡처·오버레이 호환성은 별도 확인 대상이다. **콘텐츠 장르의 적용 가능성과 플랫폼 지원 완료를 구분한다.**

## 2. VPC 본문 — 고객 프로필

아래의 고객 과업·고충·기대 이득은 사용자 원안에 기초한 고객 가설이다. 관련 연구가 한국어 고객의 고충 발생률이나 우리 앱의 효과를 직접 측정한 것은 아니다.

### 고객의 할 일 — Customer Jobs

- **J1. 내용 이해:** 일본어 대화를 알아듣고, 보고 싶은 영상·방송을 이해하며 시청한다.
- **J2. 맥락 파악:** 지금 무슨 이야기를 하는지, 앞선 대화와 어떻게 이어지는지 파악한다.
- **J3. 의사 표현:** 원하는 반응이나 생각을 일본어로 표현한다.
- **J4. 참여:** 좋아하는 콘텐츠를 매개로 방송인·다른 시청자와 대화에 참여한다.

### 고객의 고충 — Customer Pains

- **P1. 이해와 표현의 언어 장벽:** 관심 있는 콘텐츠가 있어도 일본어 대사와 대화의 의미를 충분히 이해하거나 원하는 말을 표현하기 어렵다.
- **P2. 학습과 현재 시청 사이의 간격:** 일본어 학습을 대안으로 고려하지만, 지금 보고 싶은 콘텐츠를 이해하고 참여하려는 필요가 남는다. 학습에 필요한 기간·시간은 수치로 단정하지 않는다.
- **P3. 문맥이 맞지 않는 번역:** 문장만 번역하면 인물 관계, 대화 주제, 표현의 의도를 놓칠 수 있다. 모든 기존 번역 앱의 품질이 낮다고 일반화하지 않는다.
- **P4. 번역 도구의 비용 선택:** 무료 기능의 범위와 유료 기능의 비용을 고려해야 한다. 유료 선택지의 존재[6][R6]와 고객이 실제로 비용 부담을 느낀다는 가설을 구분한다.
- **P5. 대화에서의 소외:** 팬심과 관심이 있어도 무슨 이야기인지 모르거나 반응하지 못해 참여에서 소외감을 느낄 수 있다. 한국어 고객의 소외감 발생률은 미확인이다.

### 고객의 기대 이득 — Customer Gains

- **G1. 이해:** 현재 대화의 의미와 영상 내용을 이해하고 싶다.
- **G2. 맥락:** 놓친 부분이 있어도 대화의 주제와 흐름을 파악하고 싶다.
- **G3. 표현:** 자신의 의도에 맞는 일본어로 반응·답장을 작성하고 싶다.
- **G4. 소속감:** 같은 콘텐츠를 즐기는 대화에 참여하고, 함께 즐긴다는 느낌을 얻고 싶다.

정량 배경: 해외 영상 시청 실험에서 번역 댓글의 내용 이해, 부가 정보의 맥락 이해, 일반 댓글의 공감 경험을 각각 평가했다[4][R4]. 서로 다른 댓글 유형의 자기보고 평가이며, 번역 기능이 소속감을 높였다는 인과 결과로 합치지 않는다.

## 3. VPC 본문 — 가치 맵

### 제품 및 서비스 — Products & Services

- **S1. 일본어→한국어 시청 번역:** 영상·방송의 일본어 음성을 인식하고 한국어 번역을 자막과 로그로 제공한다.
- **S2. 한국어→일본어 표현 지원:** 사용자가 작성한 한국어 반응·답장을 일본어 텍스트로 번역한다. 결과는 복사하여 채팅창에 붙여넣는 방식이다.
- **S3. 대화 주제 요약:** 최근 발화를 바탕으로 주제 변화를 점검하고, 대화 흐름을 한 줄로 요약해 표시한다.

양방향은 **일본어 음성의 한국어 자막 + 한국어 입력의 일본어 텍스트 번역**을 뜻한다. 양방향 음성 통역이나 채팅 자동 전송으로 표현하지 않는다.

### 고충 해결 방안 — Pain Relievers

- **PR1. 언어 이해 보조 → P1·P2:** 한국어 자막과 일본어 답장 번역으로 현재 시청·소통을 돕는다. 언어 학습을 완전히 대체한다고 주장하지 않는다.
- **PR2. 대화 맥락 참조 → P3:** 최근 대화, 주제 요약, 채널 정보 등을 참조해 번역한다. 관련 연구[5][R5]와 이 앱의 오역 감소 효과는 구분한다.
- **PR3. 로컬 추론 방식 → P4:** 현재 앱은 로컬 STT·번역 모델을 사용하는 구조다. 판매 가격이나 총비용 절감액은 확정하지 않았다. 하드웨어·설치 부담도 확인해야 한다.
- **PR4. 이해와 표현의 연결 → P5:** 듣는 내용과 자신의 답장을 같은 시청 흐름에서 확인하도록 돕는다. 소외감 해소는 제품의 가치 목표이며 효과 검증은 남아 있다.

### 이득 창출 방안 — Gain Creators

- **GC1. 주기적인 주제 점검과 요약 → G1·G2:** 현재 대화의 주제를 표시해 내용을 따라갈 단서를 제공한다.
- **GC2. 메타정보와 최근 대화의 활용 → G1·G3:** 채널 정보와 대화 맥락을 번역에 활용하고, 영상 제목은 요약 생성의 단서로 사용한다. 최근 일본어 발화는 답장 번역에도 참조된다.
- **GC3. 시청과 표현의 연결 → G3·G4:** 자막으로 내용을 확인하고, 한국어로 작성한 반응을 일본어로 표현할 수 있게 한다.

### 고객과 기능의 대응

| 고객 과업 | 관련 고충 | 기대 이득 | 연결하는 기능·가치 | 근거 상태 |
|---|---|---|---|---|
| J1 내용 이해 | P1 언어 장벽, P2 학습과 현재 필요의 간격 | G1 이해 | S1·PR1 한국어 자막 | 기능 구현 확인. 관련 연구[4][R4]. 앱의 고객 효과는 미측정 |
| J2 맥락 파악 | P3 문맥이 맞지 않는 번역 | G2 맥락 | S3·GC1 요약, PR2·GC2 맥락 참조 | 기능 구현 확인. 조건별 번역 연구[5][R5]. 앱의 요약·메타정보 효과는 미측정 |
| J3 의사 표현 | P1 표현의 언어 장벽 | G3 표현 | S2 일본어 답장 번역 | 기능 구현 확인. 의도 전달 정확도·답장 소요 시간은 미측정 |
| J4 참여 | P5 소외감 | G4 소속감 | PR4·GC3 이해와 표현의 연결 | 원안의 가치 목표. 국내 고객·앱의 소속감 효과는 미측정 |
| 시청 과정에서 도구 선택 | P4 비용 선택 | 비용을 고려한 지속 이용 | PR3 로컬 추론 | 구조 확인. 유료 가격[6][R6]은 확인, 부담률·절감액은 미측정 |

연결은 **설계한 대응 관계**다. 고객과 가치의 적합성(Fit)이 검증됐다는 표시로 사용하지 않는다. 우선순위는 고객 조사로 정해지지 않았다.

## 4. PPT에 사용할 정량 근거

### [1] 국내 일본 대중문화 소비 — EAI

- **출처·성격:** EAI·일본국제문화회관(IHJ), 제13회 한일 국민 상호인식조사. 연구기관 조사이며 국가승인통계로 표기하지 않는다.
- **조건:** 한국 조사는 2026년 7월 20~21일, 전국 만 18세 이상 **1,547명** 웹조사. 개요는 [EAI가 재게재한 조사 소개][R1M]에서 확인했다. 과거 조사와의 질문·표집 동일성은 추가 확인 대상이다.
- **원문 수치:** 일본 대중문화를 즐긴다는 한국 응답 비율 **2022년 18%, 2026년 42%**. 분석 본문 **표 10**.
- **사용 문안:** “EAI 조사에서 일본 대중문화를 즐긴다는 한국 응답 비율은 2026년 42%로 보고되었다.”[분석 원문][R1]
- **한계:** 음악·만화·소설 등도 포함한다. 일본어 미숙자·자막 부족자·앱 고객 수가 아니다. 인원·매출로 환산하지 않는다.
- **도표:** 두 시점 수치로 막대차트를 재작성하고 기관·연도·문항 범위를 붙인다. 연평균 성장률·시장 금액은 추가하지 않는다.

### [2] 국내 일본 콘텐츠 이용 경험 — 엠브레인 트렌드모니터

- **성격:** 전문 조사기관의 자체 조사. 정부 통계로 표기하지 않는다.
- **조건:** 2026년 5월 18~19일, 전국 만 19~59세 남녀 **1,000명**. 공개 도표는 연령 집단별 **250명**으로 표시한다. 가중치·패널 대표성 정보가 확보되지 않아 전국 인원으로 확대하지 않는다.
- **원문 수치:** 최근 1년 일본 콘텐츠 이용 경험 **64.3%**. 연령별 공개 값은 **20대 81.6%, 30대 65.6%, 40대 60.0%, 50대 50.0%**.
- **사용 문안:** “공개 도표에서 20대의 일본 콘텐츠 이용 경험은 81.6%로 나타났다.”[조사 원문][R2]
- **한계:** 연간 경험이며 정기 시청률이 아니다. 전체 값은 2024년 **65.6%**이므로 이 자료로 전체 이용률 증가를 설명하지 않는다. 요약의 일본 유튜브 유형별 **32.2%**는 세부 문항 모수 확인 전까지 PPT 수치·차트에서 보류한다.
- **도표:** [공개 인포그래픽 2][R2FIG]의 해당 항목을 확인해 차트를 재작성한다. 원본 그림 사용 시 게시자의 이용 조건을 확인한다.

### [3] 일본 실사 드라마의 시청 — Netflix

- **성격·조건:** 플랫폼이 직접 발표한 전 세계 이용 지표. **2025년 7~12월** 집계, 2026년 1월 20일 발표. views는 **총 시청시간 ÷ 작품 러닝타임**.
- **원문 수치:** **Last Samurai Standing 시즌 1: 21M views**, **Alice in Borderland 시즌 3: 25M views**.[발표 원문][R3]
- **사용 문안:** “일본 실사 드라마에서도 글로벌 시청 실적이 공개되어 있다.”
- **한계:** 고유 시청자·한국 시청자·일본어 원음 시청자 수가 아니다. 합산하지 않는다. 자막·더빙을 제공하는 플랫폼의 실적이므로 미충족 번역 수요·앱 고객 수의 근거로 쓰지 않는다. **장르 범위 설명**으로 용도를 제한한다.
- **도표:** 작품별 원문 지표와 ‘글로벌 / 2025년 하반기 / Netflix 정의의 views’를 함께 표시한다. 작품 이미지 사용 시 공식 미디어 자산 이용 조건을 확인한다.

### [4] 내용 이해·맥락 정보·공감 경험 — Lu & Chen, 2024

## 7. PPT 4페이지 구성과 발표 노트

### 스타일 기준

AGY 원본의 **밝은 배경, 남색 제목·STEP 배지, 청록·장미색·금색 구분, 맑은 고딕, 패널과 표 중심 배치**를 따른다. 슬라이드 크기·마스터·여백·글자 계층·연결 화살표는 원본을 기준으로 한다. 내용은 교체하되 전체 구성을 유지한다.

원본 그림이 올바른 주장을 뒷받침하면 활용한다. 대체 자료는 원문 표·도표 또는 출처를 붙여 재작성한 편집 가능한 차트를 사용한다. 근거 그림을 모두 제거하고 본문 텍스트로 대체하지 않는다. 조사 조건과 지표 정의는 그림 가까이에 넣고 구두 설명은 슬라이드 노트에 둔다.

### 1p. 고객과 콘텐츠 소비·시장 범위

**제목:** 일본어 콘텐츠를 즐기는 한국어 시청자와 고객 범위

| 원본 패널 위치 | 내용 | 시각 자료 |

| 우상단 | 콘텐츠 이용 경험·연령 집단[2][R2] | 전체 카드 + 연령별 차트 |

### 3p. 가치제안 캔버스

**제목:** 일본어 콘텐츠의 이해·맥락·표현·참여를 연결하는 VPC

원본과 같이 좌측 **제품·서비스**, 중앙 좌측 **Gain Creators / Pain Relievers**, 중앙 우측 **Customer Gains / Customer Pains**, 우측 **Jobs**를 배치한다. 상단 가치제안·고객군 띠도 유지한다. 본문은 2~3절, 화살표는 3절 대응표를 기준으로 한다.

- 상단 고객군: “일본어 이해·표현의 제약으로 콘텐츠를 충분히 즐기거나 대화에 참여하기 어려운 한국어 사용자.”
- 상단 가치제안: “한국어 자막·대화 주제 요약·일본어 답장 번역으로 이해와 표현을 연결한다.”
- 제품·서비스: 한국어 자막·로그 / 일본어 답장 번역 / 대화 주제 요약.
- 기대 충족: 주제 요약 / 맥락·메타정보 참조 / 시청과 표현 연결.
- 고충 해결: 이해·표현 보조 / 문맥 참조 / 로컬 추론 선택.
- 고객 기대: 내용 이해 / 흐름 파악 / 의사 표현과 소속감.
- 고객 고충: 언어 장벽·학습과 현재 필요의 간격 / 문맥을 놓친 번역 / 비용 선택 / 참여의 소외감.
- 고객 과업: 대화 이해 / 맥락 파악 / 원하는 말 표현 / 대화 참여.
- 하단: “고객 프로필·효과는 검증할 가설. 기능 대응은 현재 구현 기준.”

원본의 ‘매칭 확인’은 **‘고객 과업–기능 대응’**으로 쓴다. 검증하지 않은 순위·체크 표시·해결 완료 문구는 넣지 않는다.

**발표 노트 초안**

“오른쪽부터 보겠습니다. 고객은 일본어로 된 말을 이해하고, 흐름을 파악하고, 원하는 말을 표현하고 싶습니다. 관심은 있지만 참여하지 못할 때의 소외감과 참여하면서 얻고 싶은 소속감도 원안의 중요한 부분입니다. 왼쪽의 자막·요약·답장 번역을 이 과업에 연결했습니다. 채널 정보와 최근 대화 참조도 포함했습니다. 기능의 존재와 실제 고객 효과는 구분해 확인하겠습니다.”

### 4p. 레퍼런스

**제목:** 정량 근거와 적용 범위

표는 **번호 / 기관·저자와 연도 / 문헌·지표 / 표본·범위**로 구성하고 [1]~[7]의 원문 링크를 넣는다. [7]은 두 웹스토어 항목을 한 행에 병기한다. 내부 평가 [8]은 필요할 때 외부 레퍼런스와 구분한 보조 항목으로만 둔다.

**발표 노트 초안**

“기관, 표본, 집계 기간과 링크를 정리했습니다. 국내 조사, 글로벌 플랫폼 지표, 해외 실험, 가격·사용자 표시는 의미가 다릅니다. 신뢰할 수 있는 자료여도 우리 고객과 측정 조건이 다르면 적용 범위를 제한했습니다. 원안의 가치 목표를 유지하면서 확인된 사실과 앞으로 검증할 내용을 함께 제시했습니다.”

## 8. 근거가 부족해 확정 문안에서 뺀 주장

| 제외한 확정 주장 | 현재 처리 |
|---|---|
| 국내 잠재 고객 약 1,900만 명 | 인구 환산치이므로 사용하지 않음 |
| 국내 드라마·라이브 번역 수요 인원·금액 | 직접 집계 확보 전 미확인 |
| 외부 번역기 왕복에 항상 일정한 초 소요 | 고객·조건별 실측 전 수치 없음 |
| 3~5초가 답장 마감이고 10초면 대화 단절 | 플랫폼 전송 지연을 인지적 임계값으로 사용하지 않음 |
| 기존 도구는 실시간 STT·채팅 번역을 제공하지 않음 | 공식 기능 안내에 반례가 있어 사용하지 않음 |
| ViiTor 유료 플랜이 월 25분으로 제한됨 | 다른 제품과 혼동된 주장. 공식 안내에 유효기간 내 무제한 혜택도 있어 사용하지 않음[R7C] |
| 요약·채널 메타정보로 오역을 크게 줄였음 | 기능을 켜고 끈 비교 측정 전 효과 크기 미확인 |
| 앱이 소속감 향상·소외감 해소를 입증함 | 원안의 가치 목표 유지, 앱 효과 미검증 |
| VRAM 6~8GB 사용자 비율이 SOM임 | GPU 분포로 수요·구매·실행 가능성을 대신하지 않음 |
| 모든 사이트·원클릭 설치·1~2초 응답 검증 완료 | 현재 구현과 목표 구분. 실측·호환성 검증 전 확정 문안 제외 |
