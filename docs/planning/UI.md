# UI 설계 명세
- 디자인 : 사이드 패널 or 레이어 팝업 스타일
- 컴포넌트
    * 실시간 전사번역 영역
        - 캡쳐 시작/중지 버튼 : 현재의 start capture 버튼.
        - 오디오 번역 박스 : 현재의 실시간 번역이 나타나는 곳. 디버깅을 위해 현재의 no_speech, avg_logprob과 같은 수치가 가로막대 형태로 보여야 함. (배포 시 수치 막대는 숨기거나 삭제.)
    * 실시간 텍스트 번역
        - 텍스트 채팅 박스 : 사용자가 한국어로 보내고 싶은 채팅을 입력하는 박스.
        - 텍스트 번역 버튼 : 누르거나 텍스트 채팅 박스가 활성화됐을 때 enter를 누르면 현재 맥락에 맞춰 자연스럽고 어울리는 일본어로 번역.

# 실제 활용 예시
- 여러 개의 탭을 띄워놓고 각각 별도의 영상을 시청할 때 각각의 브라우저에서 나오는 소리를 번역해야함.
- 마찬가지로 맥락 또한 해당 브라우저 내에서 나오는 소리를 바탕으로 기억해야 함.
