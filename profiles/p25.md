# 프로파일 p25 — VRAM 8GB

> **상태: 초기 가설.** 아래 모든 수치(`-ngl 34`, 양자화, 컨텍스트 길이)는 평가 세션에서 확정한다.
> 실측 전까지 품질·지연·통과 여부를 이 문서에서 선언하지 않는다 (HARDWARE_PROFILES.md §8.4).

## 대상 하드웨어

- GPU VRAM 8GB: RTX 4060 Laptop, RTX 3060 Ti 등
- 평가는 개발기(RTX 4080 SUPER)에서 이 번들을 그대로 실행해 수행한다 (§8.4). VRAM 예산 초과 여부는 개발기에서 직접 판정 가능.

## 번들 구성

| 구성 요소 | 설정 | 비고 |
|---|---|---|
| STT | faster-whisper `large-v3-turbo`, `int8_float16` | `STT_ENGINE: faster-whisper`. 가설 |
| 번역 | gemma-3-12b-it Q4_K_M (llama.cpp llama-server, 포트 8080) | `-ngl 34` 부분 GPU 적재, 나머지 CPU |
| 컨텍스트 | `-c 4096`, `-np 1` | 컨텍스트 축소로 KV 캐시 절감 |
| KV 캐시 | `-ctk q8_0 -ctv q8_0`, `-fa on` | VRAM 절감 |
| VAD | `VAD_BACKEND: onnx` (onnxruntime, CPU) | torch 불필요 |
| 환각 게이트 | `HALLUCINATION_GATE_BACKEND: onnx` | torch 불필요 |

## 필요 파일

- `llama-server/llama-server.exe` (CUDA 빌드)
- `backend/models/google_gemma-3-12b-it-Q4_K_M.gguf` (약 7.2~7.5GB)
- faster-whisper `large-v3-turbo` 모델 (첫 실행 시 자동 다운로드)
- ONNX VAD / 환각 게이트 모델 (`backend/requirements-lite.txt` 설치 후 기존 onnx 경로 사용)

## 설치 의존성

```
pip install -r backend/requirements-lite.txt
```

torch / transformers / sentence-transformers 를 설치하지 않는다. `STT_ENGINE=qwen3-asr` 은 이 프로파일에서 사용할 수 없다.

## 실행 방법

```
set LT_PROFILE=p25
start.cmd
```

(PowerShell: `$env:LT_PROFILE = "p25"`). 런처는 `python -m backend.profile launch-args llama p25` 의 값으로 llama-server 를 띄운다.
적용 확인: 백엔드 로그에 `Profile 'p25' applied` 가 보여야 한다.

## 평가 시 확인 항목

1. **VRAM 피크 ≤ 8GB**: STT + llama-server + CUDA 컨텍스트 합산 (프로세스별 VRAM 합, 상주 + 추론 중). 초과 시 이 번들 탈락.
2. **`-ngl` 스윕 결과**: `llama-bench -ngl 0,10,20,30,34,40,99` 로 VRAM 8GB 이내 최대 `-ngl` 확정. 현재 34는 가설.
3. **분할로 인한 tok/s 하락**: prefill / generation tok/s 를 `-ngl` 별로 기록, 전부 GPU 적재 대비 하락률 기록.
4. **지연 영향**: L3 종단 지연 재생(말 끝 → 한국어 final)으로 분할에 따른 p50/p95 및 드리프트 실측. 타임아웃 폴백은 `LT_PROFILE_OVERLAYS=_measure` 로 해제.
5. **품질 하한**: L1 비열등성 판정 (양자화/분할 변경 시 실제 쓰는 설정으로 측정). Q4_K_S 등 대안 후보는 별도 평가.

## 알려진 한계

- `-ngl 34` 는 가설이며, 8GB 에서 STT 와 동시 가동 시 VRAM 여유가 부족할 수 있다 (`-ngl` 하향 필요 가능).
- 레이어 CPU 분할로 generation 속도가 떨어진다. 2초 지연 목표를 만족하지 못할 가능성이 있으며, 이 경우 지연은 기록만 하고 지원/표기는 실측 후 결정한다 (§1-2).
- 컨텍스트 4096 축소는 긴 프롬프트(용어집 등)를 제한할 수 있다.
- `STT_ENGINE: faster-whisper` 는 per-segment confidence 를 노출하지 않으므로 확률 기반 환각 필터는 비활성, 임베딩 기반 게이트만 적용된다 (qwen3 경로와 동일).
- 대안 모델(Q4_K_S, TranslateGemma-12B)은 미검증이다.
- 실기(8GB 노트북) 검증은 아직 없다. 개발기 측정은 VRAM 용량 판정과 상대 속도에만 사용한다.
