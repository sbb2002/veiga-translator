# 프로파일 P3 — RTX 3080급 (10GB)

> **주의: 이 번들의 모든 값은 초기 가설이다.** VRAM 예산, `-c 4096`, KV q8_0, turbo int8 구성은 아직 측정하지 않았다.
> 확정은 평가 세션(`docs/planning/HARDWARE_PROFILES.md` §8)에서 한다. 평가 전까지 품질·지연·VRAM 수치를 사실처럼 인용하지 않는다.

## 대상 하드웨어

- NVIDIA GPU, VRAM 10GB (RTX 3080 10GB급). CUDA 사용 가능 드라이버 필요.
- 시스템 RAM·CPU 최소 사양은 미정 (평가에서 RAM 피크를 기록한다).

## 번들 구성

| 구성 요소 | 값 | 비고 |
|---|---|---|
| STT | faster-whisper `large-v3-turbo`, `int8_float16` | `STT_ENGINE: faster-whisper`. VRAM 약 1.5GB(추정) |
| 번역 | gemma-3-12b-it Q4_K_M (llama.cpp) | 전부 GPU (`-ngl 999`) |
| 컨텍스트 | `-c 4096`, `-np 1` | 가설. 기존 프롬프트·`_final_history` 충분성 미확인 |
| KV 캐시 | `-ctk q8_0 -ctv q8_0`, `-fa on` | 가설. 품질 영향 미확인 |
| VAD | silero ONNX (`VAD_BACKEND: onnx`) | torch 불필요 |
| 환각 게이트 | MiniLM ONNX (`HALLUCINATION_GATE_BACKEND: onnx`) | torch 불필요 |

예산 근거(추정): 12B Q4_K_M 가중치 약 7.2~7.5GB + KV(c=4096, q8_0) + turbo int8 약 1.5GB ≈ 9.5GB. 여유가 매우 적다.
Qwen3-ASR 1.7B(약 4GB)는 번역 모델과 동시 적재가 불가능하므로 turbo를 쓴다. 품질은 150쌍 평가에서 통계적 동률이다
(`docs/planning/HARDWARE_PROFILES.md` §4-1).

## 필요 파일

1. 번역 모델: `backend/models/google_gemma-3-12b-it-Q4_K_M.gguf` (약 7.2~7.5GB)
2. llama-server: `llama-server/llama-server.exe` — **CUDA 빌드** (저장소 루트 기준 상대 경로). Vulkan/CPU 빌드는 이 번들 대상이 아니다.
3. STT 모델: faster-whisper `large-v3-turbo` (첫 실행 시 Hugging Face에서 내려받음, 이후 캐시 사용)
4. VAD/게이트 ONNX 모델: 기존 `backend/` 경로 설정을 그대로 사용

## 설치 의존성

```
pip install -r backend/requirements-lite.txt
```

`torch`, `transformers`, `sentence-transformers`는 설치하지 않는다. 이 프로파일은 이 셋이 없어야 동작한다.

## 실행 방법

PowerShell에서:

```
$env:LT_PROFILE = "p3"
start.cmd
```

- 런처가 `python -m backend.profile launch-args llama p3` 결과로 llama-server의 exe/모델/포트/인자를 대체한다.
- `whisper_server` 섹션이 없으므로 whisper-server는 기동하지 않는다.
- 백엔드 로그에 `Profile 'p3' applied (N overrides)` 줄이 떠야 한다.

직접 확인: `python -m backend.profile show p3`, `python -m backend.profile validate p3`.

## 평가 시 확인 항목

- [ ] **VRAM 피크 ≤ 10GB**: 번역 서버 + STT(turbo) 상주 및 추론 중 합산. 초과 시 P3 탈락.
- [ ] **`-c 4096` 충분성**: 프롬프트 + `_final_history` + 용어집이 4096 토큰 안에 들어가는지, 긴 세션에서 컨텍스트 초과가 없는지.
- [ ] **KV q8_0 품질 영향**: f16 KV 대비 L1 번역 품질(chrF++, 정성 3축) 차이가 기준선 CI 안에 있는지.
- [ ] L1 STT/번역 품질이 기준선(Qwen3-ASR + gemma-3-12b, f16 KV)과 비열등한지.
- [ ] L3 지연 재생: 드리프트 기울기와 처리 못한 문장 수(0이어야 함). 개발기 값은 상한으로만 해석.

## 알려진 한계

- 예산이 빠듯하다(약 0.5GB 전후 여유 추정). 다른 GPU 사용(게임 등)과 동시 가동 시 OOM 가능.
- `-c 4096`이 길게 이어지는 번역 맥락에 부족할 수 있다. 부족하면 `-c` 증가 또는 KV 양자화 완화가 필요하며, 그 경우 VRAM 예산을 다시 계산한다.
- faster-whisper 경로는 세그먼트별 confidence(no_speech/avg_logprob)를 노출하지 않아 확률 기반 환각 필터가 비활성이다. 텍스트 기반 임베딩 게이트만 동작한다.
- 이 번들은 개발기(RTX 4080 SUPER)에서만 측정될 예정이다. 실기(10GB GPU) 검증은 별도 단계다.
