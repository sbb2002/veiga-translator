# 프로파일 P4 — RTX 4080+ (16GB+) 기준선

`profiles/p4.yaml` 번들의 설명서. P4는 **현행 구성 그대로**이며, 평가에서 기준선(baseline) 역할을 한다
(`docs/planning/HARDWARE_PROFILES.md` §8.2). 프로파일을 켜도 동작이 달라지지 않아야 한다.

## 대상 하드웨어

- NVIDIA RTX 4080 이상, VRAM 16GB 이상 (개발기: RTX 4080 SUPER)
- CUDA 사용 가능한 드라이버, Windows 11

## 번들 구성

| 구성 요소 | 값 | 현행 기본값 위치 |
|---|---|---|
| STT | `qwen3-asr` (Qwen3-ASR-1.7B-hf, transformers CUDA) | `backend/config.py` `STT_ENGINE` |
| VAD | `torch` (torch.hub silero-vad) | `backend/config.py` `VAD_BACKEND` |
| 환각 게이트 | `sentence-transformers` (임베딩 유사도) | `backend/config.py` `HALLUCINATION_GATE_BACKEND` |
| 번역 | gemma-3-12b-it Q4_K_M, llama.cpp server, 전 레이어 GPU (`-ngl 999`), `-c 8192`, `-np 1`, 포트 8080 | `tray_launcher.ps1` `$modelPath`, `$llamaArgs`, `$llamaPort` |

## 필요한 파일

- 번역 모델: `backend/models/google_gemma-3-12b-it-Q4_K_M.gguf`
- llama-server: `llama-server/llama-server.exe` (CUDA 빌드 필수; CPU 빌드는 `-ngl 999` 때문에 기준선과 다르다)
- STT 모델: 첫 실행 시 Hugging Face 캐시에 자동 다운로드되는 `Qwen3-ASR-1.7B-hf`
- VAD 모델: 첫 실행 시 `~/.cache/torch/hub` 에 자동 다운로드되는 silero-vad (네트워크 1회 필요)

## 설치 의존성

`backend/requirements.txt` 전체를 설치한다. torch 는 CUDA 빌드로 먼저 설치한다 (파일 상단 주석 참고):

```
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install -r backend/requirements.txt
```

`transformers>=5.13` (Qwen3-ASR 필요), `sentence-transformers`, `pyyaml` 포함.

## 실행 방법

```powershell
$env:LT_PROFILE='p4'
start.cmd
```

`start.cmd` 는 `tray_launcher.ps1` 을 띄우고, 이 프로파일이 있으면 llama-server 실행 인자를
`python -m backend.profile launch-args llama p4` 결과로 대체한다. 백엔드 직접 실행:

```powershell
$env:LT_PROFILE='p4'
uvicorn backend.main:app --reload --port 8000
```

llama-server 를 따로 띄울 때는 `launch-args` 의 JSON 값을 그대로 쓴다.
백엔드 로그에 `Profile 'p4' applied (3 overrides)` 가 찍힌다. override 3개는 모두 현행 기본값과 같은 값이다.

## 평가 시 기준선 역할

- `docs/planning/HARDWARE_PROFILES.md` §8.2: 개발기에서 이 번들을 1회 재측정해 `baseline-2026-10` 으로 고정한다.
  과거 리포트 수치는 직접 쓰지 않는다.
- 모든 후보 프로파일은 이 기준선과 같은 데이터·같은 seg_id 순서로 페어드 비교한다.
- 측정값의 효력은 §8.4 표를 따른다 (개발기 값은 타깃의 상한, 외삽은 `추정` 라벨).

## 알려진 한계

- 이 번들은 개발기(16GB+ CUDA)에서만 검증 대상이다. 8GB 이하 기기에서는 적재되지 않는다.
- `README.md` 의 수동 실행 예시는 `-c 4096` 이지만 런처 기본값과 프로파일은 `-c 8192` 다. 기준선은 런처 값(8192)이다.
- Qwen3-ASR 엔진은 per-segment confidence 를 노출하지 않아 `WHISPER_NO_SPEECH_THRESHOLD` /
  `WHISPER_AVG_LOGPROB_THRESHOLD` 필터가 비활성이다. 텍스트 기반 환각 게이트만 동작한다.
- 번역 서버는 `-np 1` 이므로 동시 번역 요청을 처리하지 않는다 (백엔드가 순차 호출하는 전제).
- 지연(latency) 수치는 이 문서에 기록하지 않는다. 실측 전까지 추정하지 않는다.
- `llama-server/` 바이너리와 모델 파일은 저장소에 포함되지 않는다.
