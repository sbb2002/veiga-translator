# research

STT 품질, 번역 모델 품질을 검증하는 탐색적 연구 전용 폴더다. `bandori-playlist-maker`의
`research` 브랜치 운용 패턴을 이 저장소(단일 브랜치 운용)에 맞게 옮긴 것 — 별도 브랜치를 파지
않고, 이 폴더의 `topic/` 아래에 **주제별 폴더**를 하나씩 추가하는 방식만 유지한다.

## 폴더 구성

폴더명은 `<연구시작일 YYYYMMDD>_<연구명>` 형식이다.

| 폴더 | 주제 | 상태 |
|---|---|---|

각 폴더의 배경·방법·결과는 폴더 안의 `README.md`를 참조. 새 주제를 시작하면 위 표에 행을 추가한다.

## 주제 폴더 표준 구조

```
topic/<주제>/
├── src/
│   └── <method-N>/    # N번 방법론의 소스코드 전부 + 그 방법이 무엇인지·어떻게
│                       # 실행했는지 간략한 README.md
├── fig/                # 플롯 산출물
├── report/             # 이 주제 안에서 진행한 소규모 방법론·아이디어의 실행·검증 결과 보고서
├── ref/                # 참고자료(논문·문서 등)
└── paper.md            # 연구 종결 시 report/ 를 취합해 초록논문 형식으로 작성
```

- `src/<method-N>/`: 방법론이 여러 개면 `method-1`, `method-2`처럼 번호를 매겨 나눈다. 각 폴더
  `README.md`에 **① 이 방법이 무엇인지**와 **② 어떻게 실행했는지**를 둘 다 간략히 적는다.
- `report/`: 방법론 하나 또는 아이디어 하나를 실행·검증한 결과 기록. 여러 개 쌓일 수 있다. 아래
  "보고서·논문 공통 작성 구조"를 그대로 따른다.
- `paper.md`: 연구 종결 시 `report/` 내용을 취합해 작성. 동일 구조를 따른다.

## 보고서·논문 공통 작성 구조

`report/*.md`·`paper.md`는 아래 5개 절을 이 순서로 따른다(소제목 문구는 자유, 순서·하위구조는
고정):

1. **배경**: 왜 이 실험을 시작했는지. 보통 연구 제안자(사용자)가 작성 — 동기를 임의로 지어내지
   않는다.
2. **방법**: 실험 항목이 여러 개면 항목당 방법 절을 별개로 작성한다. 각 방법 절은 이 순서로:
   1. **용어 정리**: 키워드·변수·실험조건 정의. 간결하게, 불렛 형식. 길어지면 별도 레퍼런스
      파일로 분리하고 위치만 안내.
   2. **실험 방법**: 구현 방법을 순서대로. 넘버링 불렛으로.
   3. **평가 방법**: 결과 해석 방법과 판정 기준. "score"(또는 판정 지표)의 정의와 산출 방식을
      반드시 명시 — 사람 채점이면 척도·기준, 규칙기반이면 계산식·임계값, 통계 검정이면 어떤
      검정을 왜 썼는지.
3. **결과**: 표·플롯으로 표시하고 해석을 작성한다.
4. **결론**: 결과를 종합한 최종 결론.
5. **레퍼런스**: 본문에 못 담은 상세 내용의 출처(경로). 해당 없으면 절 자체를 생략.

## 새 연구 주제를 시작할 때

`topic/` 아래에 새 폴더를 추가하는 것으로 시작한다. 위 표에 행을 추가한다. 결과가 채택되면
`backend/`(또는 해당 코드)에 정식 반영한다.
