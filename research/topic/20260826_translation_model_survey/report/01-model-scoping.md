# 01. 번역 모델 후보 스코핑

## 배경

`docs/eval/MODEL_BENCHMARK_PLAN.md`/`research/topic/20260818_translation_model_benchmark/`에서
4개 모델(Qwen2.5-7B 베이스라인, Qwen3-14B, Gemma-3-12b-it, EXAONE-3.5-7.8B)을 비교해
Gemma-3-12b-it를 채택했지만, Qwen3-14B가 순수 품질 1위였음에도 GBNF grammar
비호환으로 미채택됐고 32B급 후보(Qwen3-32B/EXAONE-4.0-32B/Gemma-3-27B-it)는 애초
VRAM 부족으로 실행조차 안 됐다. 사용자 요청(2026-08-26)으로 오픈소스 번역 모델
전반(LLM + NMT)을 다시 조사해 "모든 모델을 다 시도"하기로 했다.

## 판단 근거 요약

- **TowerInstruct 제외**: 이 프로젝트는 일본어 음성을 한국어로 옮기는 게 목적이라, 소스
  언어(일본어) 자체를 지원하지 않는 모델은 애초에 후보가 될 수 없다 — STT 서베이 때
  canary/parakeet(영어 전용)를 제외한 것과 같은 원칙.
- **Qwen3-32B/EXAONE-4.0-32B가 Q3 양자화인 이유**: 16GB VRAM(RTX 4080 SUPER)에
  Q4_K_M(19~20GB)이 안 들어간다 — `20260818` 토픽에서 이미 겪은 제약과 동일. Q3_K_S를
  선택해 두 32B 후보의 양자화 수준을 동일하게 맞췄다(비교 공정성). 다른 7B~14B급
  후보는 전부 Q4_K_M 이상이라, **32B 두 후보는 양자화 손실만으로 실제 능력보다
  저평가될 수 있다는 점을 결과 해석 시 감안해야 한다.**
- **EXAONE-4.0-32B를 낮은 기대치로도 포함한 이유**: EXAONE-3.5-7.8B가 "한국어 네이티브
  특화"라는 선정 이유와 반대로 베이스라인보다 낮은 점수를 받았던 전례가 있고, EXAONE
  4.0 자체 논문이 "어휘가 한/영 위주, 다국어 토큰은 극소수"라고 명시해 일본어 입력
  처리력 자체가 구조적으로 약할 가능성이 있다. 그래도 32B로 커진 게 이 약점을
  상쇄하는지는 실측 전엔 알 수 없어 포함한다.
- **Seed-X-Instruct-7B가 최유망 후보인 이유**: 유일하게 "번역 전용으로 파인튜닝됐고
  일본어+한국어 둘 다 명시 지원"하는 모델. 다만 (1) CC BY-NC-ND 라이선스(개인 비상업
  사용은 가능, 재배포/2차저작물 불가로 해석), (2) 제작사가 "양자화 버전이 불안정"이라고
  직접 경고했고 공식 양자화판은 아직 없다(커뮤니티 변환판만 존재) — 실측 시 이례적
  출력(반복/붕괴)이 나올 수 있음을 염두에 둔다. (3) 표준 chat 템플릿이 없는 raw
  completion 모델이라 전용 스크립트(`translate_seedx.py`)로 별도 처리.
- **NLLB-200/MADLAD-400을 포함하는 이유**: LLM과 다른 패러다임(전용 seq2seq NMT)이라
  속도(RTF) 프로파일이 근본적으로 다를 수 있다 — "모든 모델"이라는 요청에 이 카테고리도
  넣어야 커버리지가 완전해진다. 다만 일반적으로 LLM보다 직역투가 강해 이 프로젝트의
  "자연스러운 한국어" 목표와는 태생적으로 안 맞을 수 있다는 점을 결과 해석 시 감안.

## 방법 공통사항

- 평가 데이터셋: `data/eval_set_2026-08-18.jsonl`(120클립, `docs/eval/EVAL.md` 방법론,
  이 프로젝트의 기존 번역 평가 데이터셋 — 전체 사용, 서브셋 없음).
- 지표: **chrF++**(`sacrebleu.corpus_chrf`, word_order=2) — `EVAL.md` §3.1과 동일,
  `ko_ref` 대비 `hyp_ko_from_ref`(정답 전사 직접 번역, STT 오류 배제 조건, 기존
  벤치마크와 동일 관례).
- **오차범위(95% CI)**: 페어드 부트스트랩(120개 세그먼트, 500회 재표본, 코퍼스 단위
  chrF++를 매 재표본마다 처음부터 재계산) — STT 서베이와 동일 방법론.
- **RTF**(신규 — 이전 번역 벤치마크엔 없었음): `번역 소요시간 합 / 원본 오디오 길이 합`,
  STT 서베이와 동일 정의(오디오 길이 대비 처리시간 비율).
- **script 순수성**: `EVAL.md` §3.2 S1 자동 실패 조건 중 라틴 문자 유출만 자동 채점(간체자/
  히라가나 등 다른 스크립트 유출은 이번 자동 채점 범위 밖).
- **grammar(`_KOREAN_ONLY_GRAMMAR`)**: 프로덕션 기본값인 ON으로 우선 시도하고, Qwen3
  계열처럼 붕괴가 확인되면 OFF로 전환 — 모델별로 `report/02-results.md`에 기록.
