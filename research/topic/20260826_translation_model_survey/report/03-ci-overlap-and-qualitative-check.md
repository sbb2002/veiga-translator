# 03. CI 겹침 상세 확인 + 상위 4개 정성 비교

`report/02-results.md`의 요약("상위 4개는 CI가 겹쳐 통계적 우열 없음")을 사용자가
더 구체적으로 확인 요청(2026-08-27) — ①실제로 어느 쌍이 겹치고 어느 쌍이 안 겹치는지
pairwise로 확인, ②지표로 안 갈리면 정성 비교(사람이 직접 읽고 비교)가 중요하다는
지적에 따라 상위 4개의 실제 출력을 직접 대조.

## 1. chrF++ 95% CI pairwise 겹침

`out/ci_summary.json`의 `overall.<method>.chrf++` 구간을 전 쌍 비교했다(45쌍 중
겹치는 쌍만 표시):

| 방법 | chrF++ 점추정 | 95% CI |
|---|---|---|
| Gemma-3-12b-it | 31.10 | 27.28 ~ 34.92 |
| Qwen3-14B | 30.76 | 27.88 ~ 33.80 |
| Qwen3-32B | 30.17 | 27.48 ~ 33.03 |
| EXAONE-3.5-7.8B | 28.31 | 25.53 ~ 31.03 |
| Qwen2.5-7B | 23.90 | 21.16 ~ 26.78 |
| Llama-3-8B | 20.98 | 18.39 ~ 23.71 |
| Seed-X-Instruct-7B | 15.55 | 13.17 ~ 18.36 |
| NLLB-200-3.3B | 14.59 | 11.74 ~ 17.81 |
| EXAONE-4.0-32B | 2.63 | 1.95 ~ 3.42 |
| MADLAD-400-3B-MT | 0.03 | 0.00 ~ 0.06 |

**구조는 "전부 하나로 이어진 사슬"이 아니라 3개의 분리된 군집이다**:

- **완전 클리크(4개, 모든 쌍이 서로 겹침)**: Gemma-3-12b-it / Qwen3-14B / Qwen3-32B /
  EXAONE-3.5-7.8B — 6쌍 전부 겹침. 진짜 통계적으로 구분 안 되는 그룹.
- **경계 사슬(클리크는 아님)**: EXAONE-3.5-7.8B가 Qwen2.5-7B와도 겹치고,
  Qwen2.5-7B는 Llama-3-8B와도 겹친다 — 하지만 Gemma/Qwen3-14B/Qwen3-32B는
  Qwen2.5-7B와 안 겹치고, EXAONE-3.5-7.8B와 Llama-3-8B도 안 겹친다. 즉
  "상위 4개 = 하위 6개와도 동급"으로 확장 해석하면 안 된다 — 다리 역할을 하는
  두 지점(EXAONE-3.5, Qwen2.5)만 양쪽에 걸쳐 있을 뿐이다.
- **고립된 겹침 쌍**: Seed-X-Instruct-7B ↔ NLLB-200-3.3B — 둘끼리는 통계적으로
  동급(하위권)이지만 다른 어떤 방법과도 안 겹친다.
- **완전 고립**: EXAONE-4.0-32B, MADLAD-400-3B-MT — 서로도 안 겹치고 다른 어떤
  방법과도 안 겹치는 단독 최하위권.

## 2. 상위 4개 정성 비교 (20세그먼트 무작위 샘플)

지표로 못 가르는 4개(Gemma-3-12b-it/Qwen3-14B/Qwen3-32B/EXAONE-3.5-7.8B)를
`src/sample_top4_qualitative.py`(seed=7, 120개 중 무작위 20개)로 직접 대조했다.
전문은 `out/top4_qualitative_sample.txt`. **4개 다 모델별로 뚜렷이 다른 실패
패턴**이 보였다 — chrF++ 평균에는 섞여서 안 보이지만 실사용 신뢰도에는 직접
영향을 주는 차이들이다.

### Gemma-3-12b-it — 가장 자연스러운 구어체, 그러나 드물게 "번역 포기"

일부 세그먼트에서 **번역하지 않고 일본어 원문을 그대로 되돌려주는 완전 실패**가
20개 중 2개(10%) 나왔다:

```
JA : 取扱説明書に2冊取られなかった今
gemma-3-12b-it: 取扱説明書に2冊取られなかった今        ← 그대로 echo
```
```
JA : 私のネイルは、いつも塗る時にも説明していますが...
gemma-3-12b-it: 私のネイルは、いつも塗る時にも説明していますが...  ← 역시 echo
```

나머지 18개에서는 표현이 가장 자연스러운 경우가 많았다(예: "헐, 진짜 진짜.",
"잠깐만, 초가 있네."). chrF++는 이 echo 실패를 거의 0점으로 채점했을 텐데도
전체 1위를 했다는 건 나머지 구간 품질이 그만큼 좋았다는 뜻 — 하지만 "가끔
통째로 번역을 안 한다"는 실사용 관점에서는 평균 점수보다 심각한 신뢰도
문제일 수 있다.

### Qwen3-14B / Qwen3-32B — 가장 유려하지만 한자 유출 반복

`20260818` 벤치마크에서 이미 확인됐던 **Qwen3 계열의 스크립트 순수성 약점**
(간체자/번체자 소량 유출, 당시 4.2%)이 이번 20개 샘플에서도 그대로 재현됐다:

```
JA : ロウソクがなくなれば火が消える
REF          : 촛불이 없어지면 불이 꺼진다
qwen3-14b    : 蠟燭이 없으면 불이 꺼질 거야     ← "촛불"이 한자 蠟燭 그대로 유출
qwen3-32b    : 焔이 꺼지려면 촛불이 없어져야 해  ← 焔(불꽃) 유출 + 의미도 주객전도
```

같은 "ロウソク(양초)"가 20개 샘플 안에서 3번 나왔는데, Qwen3-14B/32B는 그중
일부에서 한자를 안 옮기고 그대로 남겼다(32B가 14B보다 빈도는 낮지만 완전히
없어지지는 않음). 문장 자체의 유려함·자연스러움은 4개 중 가장 좋다는 인상.

### EXAONE-3.5-7.8B — 스크립트는 가장 깨끗하지만 어려운 구간은 회피

20개 샘플에서 한자/비한글 유출은 관찰되지 않았다(4개 중 가장 안전). 대신
**어려운 구간(말장난 등)을 번역하는 대신 다른 내용으로 얼버무리는 경향**과
**원문의 화자 어조(평서문/의문문, 격식 수준)를 바꿔버리는 경향**이 보였다:

```
JA          : ふーてらのてらは、めしてらのてら!  (말장난, 번역 난이도 높음)
qwen3-14b   : 후테라의 테라는, 메시테라의 테라!   ← 발음 유지 시도(합리적 대응)
exaone-3.5  : 이런 소리, 정말 대단해!            ← 원문 내용을 포기하고 딴 소리
```

"정석이지" → "클래식이지 않나요?"처럼 평서문을 의문문으로 바꾸는 등, 원문의
말투(반말/격식)와 다른 톤으로 옮기는 사례도 여러 번 보였다.

### 종합

4개는 정량적으로 동급이지만 **정성적으로는 서로 다른 리스크를 가진다** — 셋 다
"어느 게 더 낫다"보다 "어느 실패를 감수할 것인가"에 가깝다:

| 우려하는 실패 유형 | 추천 |
|---|---|
| 번역 자체를 건너뛰는(echo) 위험을 피하고 싶다 | Qwen3-14B 또는 Qwen3-32B |
| 한자/비한글 스크립트 유출을 피하고 싶다 | EXAONE-3.5-7.8B 또는 Gemma-3-12b-it |
| 어려운 구간에서도 끝까지 번역 시도를 원한다 | Gemma-3-12b-it 또는 Qwen3-32B |

20개짜리 수동 샘플 하나의 인상이라 이 우선순위 판단 자체를 정량적으로
검증한 것은 아니다 — 표본을 늘리거나(예: 120개 전수 사람 채점) 이 3개 실패
유형(echo/스크립트 유출/회피)을 자동 채점 규칙으로 만들어 전체 세그먼트에
돌리면 더 확실한 근거가 될 것.
