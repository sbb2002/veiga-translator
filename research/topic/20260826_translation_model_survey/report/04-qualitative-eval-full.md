# 04. 정성 평가 — 의미 충실도 / 유창성 / 뉘앙스 이전 (수동 채점, 전체 120세그먼트 × 10방법)

## 배경

`report/03`은 상위 4개(Gemma-3-12b-it/Qwen3-14B/Qwen3-32B/EXAONE-3.5-7.8B)를 20세그먼트
수동 대조해 "실패 유형 서술"만 남겼다. 사용자 요청(2026-08-27)으로 이를 STT 서베이
(`20260826_stt_model_survey_gpu_full/report/02-qualitative-eval.md`)와 동일한 방식 —
점수화된 정성 평가 — 로 확장했다. 범위는 표본이 아니라 **eval set 전체 120세그먼트,
10개 방법 전부**("전부 다 해", 2026-08-27).

## 방법

- **채점자**: Claude(Sonnet 5), 2026-08-27. `ja_ref`(정답 전사)를 기준, `ko_ref`는
  의미 확인용으로만 사용. `ko_ref` 자체가 오역/모호한 세그먼트(예: `ふざけんな`를
  "장난꾸러기라니"로 옮긴 `[07]`, 네일 용어 `地詰め` 오전사 `[100]`~`[102]`)는
  `ja_ref` 의미를 기준으로 채점.
- **세 축, 각 1(전혀 그렇지 않음) ~ 5(아주 그러함)**:
  - **의미 충실도**: `ja_ref`의 의미가 얼마나 충실히 전달되는가. 일본어 원문
    echo·설명문 대체·완전 오역 = 1.
  - **유창성**: 한국어 자체가 얼마나 매끄러운가. **정오와 무관하게** 채점 —
    유창한 오역도 이 축은 높다(STT 서베이의 "자연스러움"과 같은 역할).
  - **뉘앙스 이전**: 일본어의 말투/격식/구어체/말장난/고유명사가 한국에서 통하는
    등가 뉘앙스로 옮겨졌는가(단순 직역이 아니라).
- **유창한 환각률**: 유창성 ≥ 4 & 의미 충실도 ≤ 2 인 세그먼트 비율.
- 95% CI는 페어드 부트스트랩 2000회(평균에 대해). `src/qualitative_eval.py agg`로 표
  재생성, `--check`로 데이터 정합성 자체 검증. 점수 원본은 `out/qualitative_scores.json`,
  전문 대조표는 `out/qualitative_sample.txt`.

### 의미 충실도 — 상위 클리크가 4개가 아니라 3개다

chrF++로는 상위 4개가 통계적으로 갈리지 않았지만(`report/03`), **사람 채점 의미
충실도로는 EXAONE-3.5-7.8B가 나머지 3개보다 유의미하게 낮다.** 페어드 차 95% CI:

| 비교 | 페어드 차 (95% CI) | 겹침 |
|---|---|---|
| Qwen3-14B − Gemma-3-12b-it | +0.02 (−0.20~+0.24) | 0 포함 (동급) |
| Qwen3-32B − Gemma-3-12b-it | +0.03 (−0.21~+0.27) | 0 포함 (동급) |
| Qwen3-32B − Qwen3-14B | +0.01 (−0.17~+0.20) | 0 포함 (동급) |
| **EXAONE-3.5 − Gemma-3-12b-it** | **−0.28 (−0.51~−0.03)** | **0 제외 (열등)** |
| **EXAONE-3.5 − Qwen3-14B** | **−0.29 (−0.50~−0.08)** | **0 제외 (열등)** |
| **EXAONE-3.5 − Qwen3-32B** | **−0.30 (−0.50~−0.11)** | **0 제외 (열등)** |

즉 진짜 통계적 동급 클리크는 **Gemma-3-12b-it / Qwen3-14B / Qwen3-32B 3개**다.
EXAONE-3.5는 `report/03`에서 지적한 "어려운 구간 회피" 경향(말장난 `[47]`을
"이런 소리, 정말 대단해!"로, `[100]`을 "뒤집어서 넘겨보자"로)이 120세그먼트
전수에서 의미 충실도 점수로 드러난 것이다. 대신 유창성은 4.62로 홀로 최고 —
아래 "유창한 환각" 절 참고.

Gemma의 뉘앙스 우위는 구어체·유행어를 한국 등가로 옮기는 데서 온다: `推し`→"최애"

いつぶり?`→"오랜만에 스시잖아, 얼마나 됐지?"(`[33]`). Qwen3 계열은 한자 유출
(`蠟燭`·`焔`·`俺`·`上げ` — `[09]`,`[14]`,`[15]`,`[20]`,`[48]`)이 뉘앙스 점수를 깎는다.

## 축 간 상관 — 간섭 확인 (사용자 지적)

pooled(1200 관측), 방법 내부 세그먼트 단위:

| 상관 | pooled | 방법 내부 범위 |
|---|---|---|
| r(의미 충실도, 뉘앙스 이전) | **0.96** | 0.83~0.94 |
| r(의미 충실도, 유창성) | 0.86 | **0.48~0.85** |
| r(유창성, 뉘앙스 이전) | 0.88 | 0.58~0.87 |

두 가지가 드러난다:

1. **뉘앙스 이전은 사실상 독립 축이 아니다** — 의미 충실도와 r=0.96. "뜻이 맞으면
   뉘앙스도 대체로 맞다". 뉘앙스 점수의 정보량은 대부분 의미 충실도가 이미 담고
   있고, 순수 뉘앙스 차이(뜻은 같은데 말투만 다른 경우)는 Gemma vs EXAONE-3.5의
   한자 유출/회피 정도에서만 유의미하게 갈린다.
2. **유창성 ↔ 의미 충실도 상관이 방법마다 크게 다르다** — Gemma 0.85·Qwen2.5-7B
   0.81(높음: "유창한 번역 = 대체로 맞은 번역")인 반면 Qwen3-14B 0.48·EXAONE-3.5
   0.51·Llama-3-8B 0.53(낮음). 후자 세 모델은 **틀려도 매끄러운 한국어를 유지**한다.
   STT 서베이에서 large-v3-turbo가 보인 것과 정확히 같은 패턴.

## 유창성 분해 (유창한 환각 오염 확인)

| 방법 | 유창 전체 | 유창(충실≥3) | 유창(충실≤2) | 유창한 환각률 |
|---|---|---|---|---|
| gemma-3-12b-it | 4.40 | 4.68 | **1.64** | 0% |
| qwen3-14b | 4.51 | 4.52 | **4.29** | 4% |
| qwen3-32b | 4.42 | 4.55 | 3.33 | 5% |
| exaone-3.5-7.8b | 4.62 | 4.72 | **4.00** | 12% |
| qwen2.5-7b-baseline | 3.26 | 4.04 | 2.08 | 8% |
| nllb-200-3.3b | 3.65 | 4.25 | 2.96 | 14% |

**Gemma의 유창한 환각률 0%는 "안전"이 아니라 실패 방식이 다르기 때문이다.**
Gemma가 틀릴 때는 **일본어 원문을 그대로 되돌려준다**(`[03]`,`[11]`,`[13]`,`[72]`,
`[109]`,`[113]`,`[117]` 등 — 120개 중 7개가 의미 충실도 1점, 그중 대부분이 JA echo).
JA echo는 유창성도 1점이 되므로 "유창(충실≤2) = 1.64"로 나온다 — **틀렸다는 게
한눈에 보인다**(자기표시, fail-loud).

반대로 **Qwen3-14B/EXAONE-3.5는 틀릴 때도 유창성 4점대를 유지한다**(4.29, 4.00) —
매끄러운 한국어인데 내용이 틀린, 탐지하기 가장 어려운 유형. Qwen3-14B의 대표 사례:
`[07]` `ふざけんな`(화내는 말)를 "정말로 농담이야"로, `[28]` `宿題持ってないの?`를
"숙제 가지고 있잖아?"로(부정→긍정 뒤집기), `[51]` `意味はないかな`를 "의미가 있는
건가?"로. EXAONE-3.5: `[16]` `蹴った`(찼다)를 "이겼어!"로, `[71]` `教えてください`
(알려주세요)를 "알려드릴게요"로(방향 뒤집기).

method-level r(평균 유창성, 유창한 환각률) = 0.42 — STT 서베이(0.92)보다 약하다.
Gemma가 관계를 깬다(유창성 4.40인데 환각률 0%).

## 결론

- **의미 충실도 통계적 동급 클리크는 Gemma-3-12b-it / Qwen3-14B / Qwen3-32B 3개**다.
  chrF++로 4개였던 것에서 EXAONE-3.5-7.8B가 사람 채점으로는 유의미하게 떨어진다
  (어려운 구간 회피). **현재 프로덕션 Gemma-3-12b-it를 교체할 근거는 정성으로도 없다.**
- **Gemma의 강점은 뉘앙스 이전**(3.92, Qwen3-14B·EXAONE-3.5 대비 유의미 우위)과
  **fail-loud 실패 방식**(틀리면 일본어 echo → 즉시 탐지 가능, 유창한 환각률 0%).
  약점은 그 echo 자체(120개 중 7개)와 패션·뷰티 전문용어 구간(3.63).
- **Qwen3-14B/32B**: Gemma와 의미 충실도 동급, 유창성도 동급 이상. 단 (a) 한자 유출로
  뉘앙스가 밀리고, (b) 틀릴 때 유창성을 유지해(유창 충실≤2 = 4.29) 탐지가 어렵다.
  `docs/eval/MODEL_BENCHMARK_PLAN.md`의 "Qwen3-14B는 한국어 전용 GBNF 문법 비호환으로
  보류" 결정과 이 한자 유출은 같은 뿌리로 보인다.
- **EXAONE-3.5-7.8B**: 유창성 1위지만 의미 충실도가 클리크에서 이탈. "매끄러운데
  회피/오역" 프로필이라 실시간 자막 신뢰도 관점에서 상위 3개보다 불리하다.
- **뉘앙스 이전 축은 재사용 시 주의**: 의미 충실도와 r=0.96으로 거의 독립적이지
  않다. 다음 평가에서는 뉘앙스를 별도 축으로 두기보다 "한자/스크립트 유출"과
  "말투·격식 변경"을 자동 채점 규칙으로 분리하는 편이 정보량이 크다.
