# 배경
지난 실험인 전사모델 평가실험(research\topic\20260826_stt_model_survey_gpu_full), 번역 평가실험(research\topic\20260826_translation_model_survey)에서 바닐라 상태의 STT, 번역작업 모델의 성능을 정량적, 정성적으로 평가하였다. 그런데 해당 전사모델 평가실험에서는 각각 오디오 클립에 대해 전구간을 모두 청취한 후 그것을 전사하는 방식이었다. 따라서 실제 환경과 비슷하게 전사되었을 때와 기존 전사 평가실험 결과와 비교대조하여 어떤 차이가 있는지 파악하고 1차 목표로 VAD-STT 평가결과의 품질이 단순 STT 평가결과의 품질에 도달하도록 하고자 한다.

# 방법
- 파이프라인
오디오 클립 -> 오디오 청크화[16kHz PCM16 0.3초] -> 프레임화/VAD -> partial 트랙/finalize 판정 -> 전사 결과 수집

- 평가방법
수집한 전사결과(A)와 기존 전사평가의 결과(B), ground truth인 라벨 전사문장(C)을 놓고, A-B & A-C 비교한다.

- 정량적 평가
CER, WER, 의미 임베딩 평가

- 정성적 평가
* claude가 직접 두 문장을 대조하여 '매우 그렇지 않다 (1) / 그렇지 않다 (2) / 그럭저럭이다 (3) / 그렇다 (4) / 매우 그렇다 (5)'로 평가
* 자연스러움, 가독성 평가(eg. '2026년 8월' = '이천이십육년 팔월'. 두 문장은 같으나 가독성은 전자가 좋음.), 문장부호 엄수성 평가(?, !, . 등을 적절히 사용했는가), 환각 평가(원문에 없는 말을 그럴듯하게 지어냄)

# 유의사항
* 정량적 평가 지표, 정성적 평가 지표는 항상 오차율을 함께 기재할 것.
* 두 후보를 비교하는 작업이 필요하다면 어떤 통계검정을 사용했는지와 유의수준(p-value)를 반드시 기재할 것.
* 결과는 표로 작성하고, 표에 대한 간략한 설명을 함께 적을 것.
* 표를 적절한 그래프로 그려서 png로 저장할 것.
* 보고서 작성 시 결과 표, 그림을 반드시 활용할 것.
